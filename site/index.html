02 / GET UP AND RUNNING

From zero
to connected.

All you need is Bun and an active WhatsApp account. Set up your project, create a session, and you're good to go.

REQUIREMENTS
Bun ≥ 1.4.0
WhatsApp active account
quick startBASH
01$ git clone https://github.com/arsa0x/violajs.git
02$ cd violajs && bun install
03$ bun run generate
# Create your first session
04$ bun start create --session my-session
# Start it up
05$ bun start --session my-session
✓ Ready when you are.
